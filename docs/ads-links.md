## Τα ΠΑΛΙΑ links δεν σπάνε

545 redirects είναι ήδη στημένα. Παράδειγμα:

```
physiodanali.gr/el/physical-therapy-at-home-glyfada-gr.html
        ↓ 308 (μόνιμο)
physiodanali.gr/physiotherapy-glyfada
```

Επαληθευμένα **260/260** παλιά indexed URLs → 308 → 200, μηδέν 404.

**Πρακτικά:** τα ads συνεχίζουν να δουλεύουν χωρίς καμία αλλαγή τη μέρα του switch.
Τα νέα links μπαίνουν με την ησυχία μας (καλύτερα, γιατί γλιτώνουν ένα hop).

## Δεν υπάρχει ακόμη

**Νευρολογική φυσικοθεραπεία** — στο παλιό site είχε 8 URLs (γενικό + ανά περιοχή).
Τώρα όλα προωθούν στο `/home-care`. Αν θέλει ads σε νευρολογικά keywords
(εγκεφαλικό, Πάρκινσον, σκλήρυνση κατά πλάκας), χρειάζεται δική της σελίδα.
